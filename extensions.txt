# Extension groups for install.sh.
#
#   ./install.sh                                  # [core] only
#   ./install.sh --groups core,k8s,ops            # several groups
#   ./install.sh --groups all --profile Cybersec  # into a VS Code profile
#
# To customise: add an id under a group, or start your own [group] header.
# Every publisher must also be listed in "extensions.allowed" in settings.json,
# otherwise VS Code blocks the install.
#
# "closed source" marks an extension that ships under a vendor licence with no
# public source: kept for capability, but it cannot be reviewed before it runs.
# "unmaintained" marks one whose last Marketplace release is years old — an
# idle popular publisher account is what a takeover targets.
